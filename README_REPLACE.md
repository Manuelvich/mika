# Замена проекта

В этой версии строка быстрых ссылок в шапке чата содержит 5 фиксированных слотов одинаковой ширины.
На телефоне слоты равномерно распределяются по ширине экрана с одинаковыми боковыми полями.

Рекомендуемое обновление без удаления томов:

```bash
COMPOSE_PARALLEL_LIMIT=1 docker compose build web
COMPOSE_PARALLEL_LIMIT=1 docker compose up -d web
```

Не используйте `docker compose down -v`.
