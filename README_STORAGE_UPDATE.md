# Обновление: presence, звонки и личное хранилище

Добавлено персональное хранилище с папками, загрузкой нескольких файлов, переименованием, удалением, скачиванием и созданием публичной ссылки на файл или ZIP папки.

Статус последнего посещения теперь имеет резервное значение для старых пользователей и обновляется heartbeat-сообщениями WebSocket.

Видеозвонок запрашивает камеру и микрофон одним системным запросом. После завершения дорожки останавливаются, чтобы индикатор камеры/микрофона погас.

Важно: iOS может повторно показывать системный запрос при каждом новом getUserMedia, если для сайта стоит режим «Спрашивать». Для постоянного разрешения выберите «Разрешить» в настройках веб-сайта Safari/PWA.
