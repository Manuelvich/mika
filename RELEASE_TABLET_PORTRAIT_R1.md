# Tablet portrait reliability release

Исправлено:

- мобильный док принудительно отображается на Android-телефонах и планшетах с сенсорным вводом;
- док закреплён у нижней границы видимого экрана;
- свойства контакта, профиль, управление группой и другие окна ограничены высотой экрана и прокручиваются внутри;
- для установленной PWA задана ориентация `portrait`;
- в горизонтальном положении на сенсорных устройствах показывается экран с просьбой повернуть устройство;
- добавлена попытка системной блокировки ориентации там, где браузер это поддерживает;
- обновлена версия PWA-кэша.
