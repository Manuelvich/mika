# Mobile keyboard r9

Исправлено смещение строки ввода чата на iPhone при открытии экранной клавиатуры.

- учитываются `visualViewport.height` и `visualViewport.offsetTop`;
- во время ввода скрывается нижний чатовый dock;
- область сообщений сжимается, а composer остаётся у нижнего края видимой области;
- обновлены версии приложения и service worker.
