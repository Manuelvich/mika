# Mobile taskbar R2

Исправления:

- мобильный taskbar принудительно включается по ширине экрана, даже если iOS PWA неверно определяется как desktop;
- service worker регистрируется при запуске с новой версией и очищает старый кэш;
- `index.html` и `sw.js` отдаются без кэширования;
- завершённые и неотвеченные звонки старше 2 минут не восстанавливаются;
- старые call-уведомления закрываются после проверки или завершения звонка.

Обновить необходимо backend и web.
