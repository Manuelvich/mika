# Mobile UI v2.1 — финальный образ на 14.07.2026

## Контакты
- Персональный псевдоним контакта.
- Персональная категория: Семья, Друзья, Работа или без категории.
- Личная заметка о контакте.
- Все поля находятся в разделе «Информация» как на телефоне, так и на компьютере.
- По умолчанию используется имя, заданное самим пользователем.
- Псевдоним, категория и заметка видны только владельцу настроек.

## Главная
- Личные чаты группируются: Семья → Друзья → Работа → Другие.
- Пустые категории не отображаются.
- Групповые чаты вынесены в отдельный раздел «Группы».
- В списке и заголовке чата показывается персональный псевдоним, если он задан.

## Сообщения
- Входящие сообщения выровнены слева.
- Исходящие сообщения выровнены справа.
- Максимальная ширина пузыря ограничена 75% области чата.

## Обновление базы
При запуске backend автоматически добавляет в таблицу contact_categories поля alias и note.
