# Desktop UI v2

Полностью переработанный десктопный интерфейс по согласованному макету.

## Изменения

- узкая навигационная панель слева;
- отдельная колонка списка чатов;
- компактная шапка чата только со звонком, видео и информацией;
- правая контекстная панель;
- быстрые ссылки перенесены в правую панель;
- сообщения и строка ввода переработаны;
- URL в тексте сообщений отображаются как кликабельные ссылки;
- мобильный интерфейс сохранён отдельно;
- обновлена версия service worker.

## Обновление

```bash
COMPOSE_PARALLEL_LIMIT=1 docker compose build web
docker compose up -d web
```
