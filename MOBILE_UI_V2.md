# Mobile UI v2

Изменения:
- единый светлый скандинавский стиль для iPhone и Android;
- крупный нижний dock без внешнего зазора;
- адаптация по фактическому viewport, safe-area и высоте экрана;
- при клавиатуре dock скрывается, composer остаётся над клавиатурой;
- во время входящего, исходящего и активного звонка dock и composer скрыты;
- плавающие модальные окна поверх интерфейса;
- облегчённая типографика Files и компактный список приложений;
- новый звук входящего сообщения;
- надёжное обновление last_seen при API, сообщении и WebSocket-событиях;
- новая версия service worker.
