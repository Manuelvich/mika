# Igorson Workspace Desktop v2

В этой сборке переработан Desktop-интерфейс без изменения API и базы данных.

## Основные изменения

- единый Dock: Чаты, Моё пространство, Приложения, Избранное, Настройки;
- устранены дублирующиеся пункты навигации;
- новый трёхколоночный экран чатов;
- отдельный полноразмерный файловый менеджер вместо старого модального окна;
- отдельная страница приложений, использующая три ссылки профиля;
- веб-приложения открываются во всю рабочую область, Dock остаётся видимым;
- обновлены типографика, размеры иконок, отступы, сообщения и строка ввода;
- обновлена версия service worker.

## Обновление

```bash
COMPOSE_PARALLEL_LIMIT=1 docker compose build web
docker compose up -d web
```

После обновления выполните полную перезагрузку страницы. При старом PWA-кэше полностью закройте приложение и откройте снова.
